IdentityGuard

Un module PowerShell qui audite la sécurité des identités sur Active Directory et Entra ID (16 contrôles), puis produit un rapport HTML avec un score, la gravité et la correction de chaque point.

Ce qu'il contrôle

  • Active Directory : âge du mot de passe krbtgt, comptes Kerberoastables et AS-REP roastables, délégation non contrainte, groupes à privilèges, comptes inactifs, LAPS
  • Entra ID : utilisateurs sans MFA, rôles à privilèges permanents, invités, accès conditionnel, secrets d'applications qui expirent
  • Chaque constat renvoie vers MITRE ATT&CK ou la documentation Microsoft
PowerShellMicrosoft GraphActiveDirectoryPesterGitHub Actions

67 tests Pester, validés en CI sur Linux, Windows et Windows PowerShell 5.1.

Hermes

Comparateur de budgets pour les dépôts de brevets. L'équipe choisit un client et des pays, puis l'outil calcule les annuités et produit un devis PDF.

Sécurité intégrée dès la conception

  • Jetons CSRF générés avec random_bytes et vérifiés avec hash_equals
  • Cookies de session Secure, HttpOnly et SameSite
  • Accès MySQL par PDO, contrôle d'authentification sur chaque page
  • Tableau de bord admin pour gérer les comptes
PHPMySQLPDOJavaScriptBootstrapDOMPDF

Outil interne : le code reste privé. Démonstration possible en entretien.
