IdentityGuard

Un module PowerShell qui audite la sécurité des identités sur Active Directory et Entra ID (16 contrôles), puis produit un rapport HTML avec un score, la gravité et la correction de chaque point.

Ce qu'il contrôle

  • Active Directory : âge du mot de passe krbtgt, comptes Kerberoastables et AS-REP roastables, délégation non contrainte, groupes à privilèges, comptes inactifs, LAPS
  • Entra ID : utilisateurs sans MFA, rôles à privilèges permanents, invités, accès conditionnel, secrets d'applications qui expirent
  • Chaque constat renvoie vers MITRE ATT&CK ou la documentation Microsoft

EntraLifecycle

Un module PowerShell qui automatise le cycle de vie des identités Entra ID (arrivées, mutations, départs) à partir d'un export RH CSV. Il construit d'abord un plan, à la manière de terraform plan : rien n'est modifié tant que le plan n'est pas appliqué.

Ce qu'il fait

  • Arrivée : UPN sans accents, gestion des homonymes, groupes et licence selon le poste, manager, Temporary Access Pass à usage unique
  • Mutation : retire les groupes devenus inutiles, pour rester au moindre privilège
  • Départ : désactivation, révocation des sessions, retrait des groupes, licence retirée plus tard, jamais de suppression
  • Journal d'audit qui ne contient jamais le TAP, rapport HTML du plan, correspondance ISO 27001:2022 et guide d'hygiène de l'ANSSI
