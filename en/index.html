IdentityGuard

A PowerShell module that audits identity security across Active Directory and Entra ID (16 checks), then produces an HTML report with a score, plus the severity and the fix for every finding.

What it checks

  • Active Directory: krbtgt password age, Kerberoastable and AS-REP roastable accounts, unconstrained delegation, privileged groups, stale accounts, LAPS
  • Entra ID: users without MFA, standing privileged roles, guests, Conditional Access, expiring app secrets
  • Every finding links to MITRE ATT&CK or Microsoft documentation

EntraLifecycle

A PowerShell module that automates the Entra ID identity lifecycle (joiners, movers, leavers) from an HR CSV export. It builds a plan first, like terraform plan: nothing changes until the plan is applied.

What it does

  • Joiner: UPN without accents, homonym handling, groups and licence by role, manager, one-time Temporary Access Pass
  • Mover: removes groups that are no longer needed, to stay at least privilege
  • Leaver: disable, revoke sessions, remove groups, licence removed later, never delete
  • Audit log that never contains the TAP, HTML plan report, mapping to ISO 27001:2022 and the ANSSI hygiene guide
